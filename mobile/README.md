# Mobile App - Restaurant Order System

Aplicación móvil utilizada por meseros y cocina para gestionar pedidos en tiempo real.

---

# Tecnologías

React Native  
Expo  
React Navigation  
Supabase Client  
Zustand  
Tamagui  

---

# Funcionalidades

Registrar pedidos  
Seleccionar mesas  
Agregar productos  
Enviar pedidos a cocina  
Ver estado del pedido

# Ejecutar aplicación

Entrar a la carpeta

cd mobile

Instalar dependencias

npm install

Ejecutar aplicación

npm start

Esto iniciará Expo Dev Server.
